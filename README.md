# robot-learning
Learning-by-doing Robot Learning, in public.

All code here is written by me, with one exception: [scripts/box/](scripts/box) holds infrastructure scripts generated by Claude Code under my direction (see its README).

## Setup note (macOS)

Create a `.env` file in the repo root containing `KMP_DUPLICATE_LIB_OK=TRUE` (duplicate OpenMP runtimes from the torch wheel + conda ffmpeg; terminals get it via pixi automatically, this covers VS Code notebook kernels).
