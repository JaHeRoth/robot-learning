# box

Tooling for the cloud GPU boxes, generated by Claude Code under my direction:

- `setup_box.sh`: setup checklist for a fresh box
- `merge_lerobot_datasets.py`: merge dataset shards generated in parallel
- `sweep_checkpoints.py`: re-evaluate every checkpoint of a run over many seeds

The PushT eval farm from the training block (eval daemon, 5000-seed fragment evals, Hub uploads) is in `scripts/box/` at the tag `pusht-box`.
